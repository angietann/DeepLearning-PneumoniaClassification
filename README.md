# Deep Learning - Pneumonia Classification

Pneumonia Classification Using CNN & Transfer Learning

This project explores deep learning approaches for pneumonia classification using chest X-ray images. The study compares custom Convolutional Neural Network (CNN) architectures and transfer learning using a pre-trained VGG16 model.

Project Overview

The objectives of this project are to:

- Classify pneumonia from chest X-ray images
- Compare the performance of custom CNN and pre-trained VGG16 models
- Evaluate the impact of architectural modifications on model performance
- Experiment with parameters tuning (Learning rate)
- Analyze differences between traditional CNN and transfer learning approaches

**Models Implemented**

- Custom Baseline CNN architecture
- Custom CNN (with modified learning rate)
- Pre-trained VGG16 model
- Pre-trained VGG16 (with modified learning rate)

**The project includes comparisons between:**

- CNN vs Modified CNN
- VGG16 vs Modified VGG16
- Overall CNN vs VGG16 performance


**Tech Stack**

- Python
- TensorFlow / Keras
- Scikit-learn
- Matplotlib
